## 1. Рамка

**Рабочее название [G0, с руководителем]:** *When does solver quality matter? A pre-registered
benchmark of exact methods and QUBO-based heuristics for cardinality-constrained portfolio
selection, from in-sample optimality to out-of-sample performance.*

**Журнал:** *Computers & Operations Research* (Elsevier). Квантовая часть (QAOA, симуляция на
GPU, чип Octillion) в статью не входит, она в магистерской ВКР (решение 2026-10-07).

**Задача.** Модель MV с кардинальностью, только длинные позиции:

`min f(w) = −μᵀw + (λ/2)·wᵀΣw` при `Σw = 1`, `l·z ≤ w ≤ u·z`, `Σz ≤ K` (у ORlib `= K`, §3),
`z ∈ {0,1}^N`.

- `l` — минимальная покупка (R16); `l = 0` у всех семейств, кроме ORlib.
- μ и Σ годовые, λ — коэффициент неприятия риска. Тогда `−f(w)` — годовой эквивалент
  определённости (CE) в выборке, и зазор `ĝ_CE = (f − f*)·10⁴` измеряется в б.п. CE.
- Вариант с оборотом `+ c·Σ|w − w_prev|` — только разведочно (§9, M13).

**Вклады.** Для C&OR их три: два методологических и один эмпирический.
1. **Протокол атрибуции зазора суррогатного конвейера** «QUBO-сэмплер → пул K-подмножеств →
   выпуклая доводка».
   - Центральный объект — **потолок суррогата** `E_form(m)`: зазор оракула, возвращающего m
     лучших состояний равновесного binary-inclusion суррогата.
   - Это предел, к которому сходится конвейер по мере того, как сэмплер всё лучше минимизирует
     *данный* суррогат. Сюда входят и идеальный аннилер, и QAOA.
   - Это не нижняя граница для любого сэмплера: при `E_samp < 0` конвейер обыгрывает потолок
     (RQ1).
2. **Честный бенчмарк** QUBO-эвристик против открытых точных методов и прямого локального поиска по
   истинной цели на инстансах со связывающей кардинальностью. Эффекты оцениваются с полосой
   практической эквивалентности (RQ2, ядро статьи).
3. **Протокол оценки ценности точности вне выборки**: сертифицированные k лучших альтернативных
   носителей с фактической дозой зазора, тесты эквивалентности, плечо GMV для контраста с Gilli &
   Schumann (RQ3). Контролируемая инъекция заменами носителя — описательно.

**Связь со статьёй ИСП РАН (M1).** Та же задача, конвейер и рынки. Отличия раскрываются в разделе
рукописи «Relation to prior work» таблицей «что было → что исправлено → что ново» и в
сопроводительном письме, с перечнем заменяемых опубликованных утверждений.
- Аннотация прошлой статьи называет три механизма зазора, но её эксперименты их не разделяли
  (текст прошлой статьи это признаёт). Атрибуция RQ1 — новый результат, а не повтор.
- Исправление в журнал ИСП РАН не отправляется (решение пользователя 2026-10-04). Поэтому
  legacy-числа в новой статье не используются, включая неопубликованное «ускорение 21.6×».
- Перерасчёт Эксп. D исправленным движком (`docs/E0_legacy_delta.md`) — только приложение, не
  новый результат.
- Ошибки прошлой статьи, которые нельзя повторять, — `docs/errata/ISP_RAS_2026_errata_draft.md`.
- Терминология: «QUBO-based heuristics» вместо «quantum-inspired» (R11).

## 2. Исследовательские вопросы и гипотезы

Подтверждающие тесты, их стороны, ячейки и поправки на множественность сведены в реестр §7.1.
Всё, чего там нет, — оценивание или описание. Исходы и формулировки — §10.

### RQ1 (E1). Где предел суррогата и чем его можно обойти?

**Определения.**
- **Доводка** `refine(S)` — оптимум истинной задачи на носителях внутри K-подмножества S:
  - при `l = 0` — выпуклая QP на S с `0 ≤ w_i ≤ u` (носитель может быть меньше S), что согласовано
    с `Σz ≤ K`;
  - у ORlib (`Σz = K`, `l = ε`) — QP на S с `ε ≤ w_i ≤ δ` для всех бумаг S; `f*` считается при той
    же `Σz = K` (N11).
  - Обозначим `F(S) = f(refine(S))`. Реализация одна для всех методов (§4).
- **Суррогат** — равновесный binary-inclusion QUBO, `w = x/K` (`cif.qubo.builder.build_selection_bqm`).
  Для оракула ограничение `|S| = K` задаётся жёстко, а не штрафом, поэтому `E_form` от множителя
  штрафа не зависит (M3).
- **`T_m`** — m лучших K-подмножеств по энергии суррогата, полным перебором (`C(N,K) ≤ 2·10⁶`).
- **`f*`** — сертифицированный оптимум истинной задачи (§5).
- **Потолок суррогата:** `E_form(m) = min_{S ∈ T_m} F(S) − f*`.
- **Конвейер (атрибуционный протокол):**
  - один вызов сэмплера даёт уникальные допустимые K-подмножества, упорядоченные по энергии
    суррогата;
  - `P̂_m` — первые m из них; если их меньше m, `P̂_m` — все, что есть, и число отчитывается
    (minor 2);
  - `E_pipe(m) = min_{S ∈ P̂_m} F(S) − f*`.
- **Остаток сэмплера:** `E_samp(m) = E_pipe(m) − E_form(m)`. Отрицательный остаток значит, что
  разнообразие пула ценнее точной минимизации суррогата.
- **Нормировка** (§5): `ĝ = (F − f*) / s*`.

Это **атрибуция**, а не разложение на независимые причины: `E_pipe = E_form + E_samp` — тождество.
Штраф, расписание температуры и размер пула — факторы, модулирующие `E_samp`. Они анализируются
вложенными моделями §7.3.

**Ячейки RQ1 (N9).**
- Семейство `factor`, `λ = 5`, `l = 0`, `u = 1`, параметры генератора по умолчанию, кроме фактора
  `h`.
- `h = vol_dispersion ∈ {0.15, 0.45}` — **разброс волатильностей (и β)**: генератор меняет и μ
  через β (minor 13).
- `N ∈ {16, 24}`, по 40 тестовых сидов на N. Сиды у уровней h **общие**, дизайн парный: 80 пар,
  160 инстансов.
- K задаётся **на пару**: `K = min(8, max(3, ⌊min(s_cont(h = 0.15), s_cont(h = 0.45))/2⌋))`.
  K в паре общий, обе половины связывают, а перебор остаётся в пределах `C(24, 8) ≈ 7·10⁵`.
  Глубина связывания `s_cont/K` по h отчитывается.
- Нижняя граница 3 (v2.4) убирает вырожденные пары с K = 2. Там `T_200` покрывает 72 % и больше
  всех K-подмножеств (`C(24, 2) = 276`, `C(16, 2) = 120`), и `E_form(m ≥ 50)` нулевой тривиально.
  Диагностика дизайна на сидах 90 000–90 199 (только `s_cont` и K, §9): с границей 2 у 3 % пар
  K = 2 при каждом N; с границей 3 обе половины связывают в 99.5 % пар при N = 16 и в 100 % при
  N = 24.
- Пары не заменяются. Доля связывающих (`s_cont > K`) и фактический коэффициент вариации
  волатильностей отчитываются по h.
- Подтверждающие утверждения RQ1 — только при `N ≤ 24`, где `f*` и `T_m` сертифицированы. Большие
  N в RQ1 не рассматриваются.

**Гипотезы.**
- **H1a (потолок растёт с разбросом волатильностей).** `E_form(m₀)` при `h = 0.45` больше, чем при
  `h = 0.15`.
  - Тест: односторонний знаковых рангов Уилкоксона, стратифицированный по N, по разностям в парах.
  - `m₀ = 50`, если на 40 калибровочных парах (§3) `E_form(50) > τ` хотя бы у 20 % инстансов;
    иначе `m₀ = 1` **[пилот]**.
  - Оценки (не тесты): доля инстансов с `E_form(m) > τ`, `τ = 10⁻³`, при `m ∈ {1, 50}` с ДИ
    Уилсона; величины с бутстрап-ДИ.
  - Направление ожидаемо a priori: равновесный суррогат точен, когда оптимальные веса близки к
    равным. Поэтому информативна величина, а тест — проверка (N9).
- **H1c (повторение разведки на невиданных семействах, M2, M6).** При равном бюджете 10 с
  end-to-end и равной настройке (§6) tabu даёт меньший итоговый зазор, чем SA.
  - Итоговый зазор — инкумбент anytime-прогона в момент 10 с, медиана по 10 сидам.
  - Ячейки: C1–C3 (`factor`, N = 100, 200, 400), все тестовые инстансы (60–120 по правилу n, §3).
  - Тест: односторонний знаковых рангов, стратифицированный по N. Сертификат не нужен:
    разность `F_tabu − F_SA` от `f*` не зависит.
  - Это *held-out replication* разведочного вывода. Направление показано независимо у Lozano
    (2026), поэтому вклад — строгая постановка. ORlib — описательно: 5 кластеров дают минимальное
    точное p = 1/32 (N8).
- **Пул (бывшая H1b, M5).** Пулы вложены, поэтому монотонность по m верна по построению и не
  проверяется. Оценивается кривая «качество — полное время» по `m ∈ {1, 5, 20, 50, 200}` —
  описательно.
- **Механизм плато SA (бывшая H1d) — разведочно (M6).** Вложенные факторы §7.3: множитель штрафа
  (SA, tabu), диапазон β (только SA), тип хода (флип против обмена, сохраняющего K).

### RQ2 (E2). Нужны ли QUBO-эвристики против точных методов и прямого локального поиска?

Только связывающие инстансы (`s_cont > K`, R4). Сравниваются **представители классов**. Их
выбирают на калибровке по одному критерию — медианному PI за 10 с (§6, N6):
- **точный:** лучший из {SCIP big-M, SCIP perspective с `D = λ_min·I`, SCIP perspective с D из SDP,
  OA с мастер-задачей HiGHS multi-tree (Bertsimas & Cory-Wright 2022, без ridge)}. SDP-вариант —
  только при N ≤ 150: выше плотная SDP-задача не помещается в память (разведочный замер E0), и
  кандидатов три. У SCIP-вариантов `misc/usesymmetry` — параметр настройки (прил. Б);
- **QUBO-конвейер:** лучший из {SA, tabu, swap-SA} после равной настройки;
- **прямой локальный поиск (LS) по истинной цели:** жадный отбор + обмены одной бумаги с доводкой и
  рестартами, без суррогата (класс Di Gaspero et al. 2011).

**Оцениваемая величина (minor 3).** Для инстанса — `R = PI(QUBO) / PI(точный)` (H2) и
`R_b = PI(QUBO) / PI(LS)` (H2b). PI — primal integral за 60 с с общим стартом (§5). Для
стохастических методов берётся медиана по сидам, для SCIP — по сидам перестановок. `R < 1` значит,
что QUBO лучше.

**Подтверждающая оценка (N8)** — сводная: среднее `log R` по ячейкам C1, C2, C3, C5 (и C4, если
она допустима, §3) с равными весами ячеек. ORlib внутри C5 — среднее по port из средних по λ.
- 95 % ДИ — стратифицированным бутстрапом: инстансы в ячейках, port в C5.
- Ячейки — описательно, с одновременными 99 % ДИ (Бонферрони).
- Полоса практической эквивалентности — `[1/1.5, 1.5]`.

**Исходы H2 и H2b** (одинаково, §10):
- «QUBO лучше» — ДИ целиком ниже 1/1.5;
- «QUBO хуже» — ДИ целиком выше 1.5;
- «практически эквивалентны» — ДИ внутри полосы;
- «направление установлено, величина не определена» — ДИ исключает 1, но пересекает край полосы;
- «неопределённо» — иначе.

H2b отвечает на вопрос, нужен ли QUBO-обход вообще (M7, M11).

**Вторично.**
- Time-to-target с теми же исходами (§5).
- У точных методов `t_primal` и `t_cert` — раздельно.
- Performance profiles.

**Валидация бейзлайна (M11).**
- Точный стек решает исходную задачу BCW (2022, табл. 3: ORlib с ограничением на доходность) и,
  если загрузку FG разрешат, WK (табл. 1). Отчитывается отношение «наш стек / опубликованное».
- Если отношение больше 10, выводы RQ2 формулируются только как сравнение с *открытыми* точными
  методами, а исход «QUBO лучше» сопровождается оговоркой о бейзлайне.

### RQ3 (E3). Важна ли точность оптимизации вне выборки?

**Рынки.**
- **FF49 — первичный.** Это «лаборатория без смещения выживаемости»: кардинальность по отраслевым
  портфелям экономически слабее, чем по акциям, а издержки на отраслевой портфель условны.
- **US — вторичный**, только H3a для MV.
- **RU** — разведочно, и только с поштучными дивидендами (§3): выгрузка Cbonds и реестр выплат по
  официальным раскрытиям для эмитентов, которых в ней нет. Иначе RU исключается из статьи: на
  индексном уровне оптимизации нет.

Параметры walk-forward — §3.

**Плечи.**
- **MV:** цель §1 с `λ_f` (§3).
- **GMV:** `min wᵀΣw` с той же кардинальностью и u, как у Gilli & Schumann. Зазор в выборке
  `ĝ_CE = (λ_f/2)·(wᵀΣw − w*ᵀΣw*)·10⁴` б.п. (minor 5).

**Операторы зазора (M12, N2; v2.4).** Для фолда f с сертифицированным оптимумом `w*_f`. В v2.3
первичным был оператор (б) с фиксированными уровнями. Разведочный замер (§9) показал, что малые
уровни заменами носителя недостижимы, поэтому первичный теперь (г) (консультация рецензента
`docs/reviews/2026-10-08-q1-rq3-operator-consult.md`).

**(г) k лучших носителей — первичный.**
- **Ранг.** Объект — различные *доведённые* портфели: носители `T = supp(refine(S))` по
  K-подмножествам S, упорядоченные по `F`; носитель — `{i : w_i > 10⁻⁶}`. Ровно их выдаёт
  конвейер «пул → доводка», когда промахивается.
- **Перечисление.**
  - Ранг 1 — сертифицированный оптимум, `T_1 = supp(w*_f)`.
  - Ранг k + 1 — оптимум MIQP (`Σz = K`, `w ≤ u·z`, `l = 0`) с отсечениями надмножеств
    `Σ_{i∈T_j} z_i ≤ |T_j| − 1` для всех найденных `j ≤ k`. При `l = 0` оптимум тот же, что при
    `Σz ≤ K`. Равенство нужно, чтобы перечень состоял ровно из доводок K-подмножеств: при
    `Σz ≤ K` MIQP возвращает и портфели на меньшем числе бумаг, которые никакое K-подмножество не
    даёт (разведочная проверка перебором на N = 8 и 12).
  - Перечень исчерпывающий для доводок K-подмножеств, без повторов и упорядочен по `F`:
    разрешённое множество, содержащее `T_j`, доводится до портфеля не хуже `T_j`.
  - Обычные no-good-отсечения по z неверны: при `l = 0` тот же портфель возвращается с другим
    набором z (на несвязывающем фолде — `C(N − |supp|, K − |supp|)` копий оптимума).
- **Портфель ранга** — `refine(T_r)` (общая доводка, `l = 0`, u фолда). **Доза** —
  `ĝ_{f,r} = (F(T_r) − f*)·10⁴` б.п. CE; для GMV — по формуле плеча.
- **Ранги:** FF49, оба плеча — 2–33 (R = 32); US-MV — только ранг 2.
- **Сертификат:** каждая MIQP ранга — с `limits/absgap = 10⁻⁶·s_ref`, как у оптимума, лимит 600 с.
  Доза пересчитывается точной доводкой и от допуска MIQP не зависит.
- **Ничьи:** портфели с равными `F` — цепочки соседних рангов с разностями не больше абсолютного
  зазора SCIP `10⁻⁶·s_ref` — упорядочиваются лексикографически по отсортированному носителю.
  Ранг 1 (оптимум) не переставляется: альтернатива, равная ему, помечается ничьей с дозой ≈ 0.
  Для проверки ничьей на границе перечисляется ранг R + 2; ничья на границе отчитывается, но фолд
  не исключает. Доля ничьих — доля пар соседних рангов 1–33 с равными `F` — отчитывается по плечам
  на `F_k`. Почти совпадающие портфели (отличие — бумага с весом порядка 10⁻⁴) — отдельные ранги.
- **Тёплый старт SCIP** — лучший сосед на одну замену.
- Ранг 2 — лучший портфель, не содержащий весь носитель оптимума. На связывающих фолдах это обычно
  лучший сосед на одну замену. Это *лучшие* ошибки — замена на близкий по оценкам аналог, поэтому
  вывод не переносится на произвольную ошибку того же размера (§10).

**(б) Замены носителя — описательно.**
- Уровни `g ∈ {1, 2, 5, 10, 25, 50, 100}` б.п. CE; на уровне строится R = 30 реплик с зазором в
  выборке `ĝ_CE ∈ [g, 1.1·g]`.
- Состояния — K-подмножества. Старт `S₀ ⊇ supp(w*)`: носитель оптимума, дополненный бумагами с
  наибольшими весами непрерывной релаксации; `F(S₀) = f*`.
- Ход — обмен одной бумаги из S на одну вне S, равновероятно.
- Энергия: `E(S) = max(0, g − ĝ(S)) + max(0, ĝ(S) − 1.1g)` (расстояние до полосы).
- Принятие по Метрополису с температурой `T = 0.25·g`.
- Реплика — состояние в момент **первого попадания** в полосу. Каждая реплика — независимая цепь
  от `S₀`.
- Не более 200 шагов на цепь и 11 цепей на реплику (первая и до 10 перезапусков). Лимита по
  времени нет: работа ограничена детерминированно, не больше 66 000 доводок на пару фолд–уровень,
  поэтому статус уровня от машины не зависит. `n_evals` отчитывается.
- **Проверка достижимости до MCMC:** `ĝ` для всех соседей `S₀` на одну замену. Если наименьший
  положительный `ĝ` среди них больше `1.1·g`, уровень на фолде недостижим и MCMC не запускается.
- Уровень на фолде достигнут, только если найдены все 30 реплик.
- Сиды — `SeedSequence((база, фолд, уровень, реплика))` (minor 6).
- Реплики независимы между фолдами. Лишний оборот, который это создаёт, в метрику до издержек не
  входит (N1).
- Отчитываются доли фолдов, где уровень достигнут, распределение фактических `ĝ`, доля отказов,
  оборот реплик против оптимума и разности Sharpe по достигнутым уровням (по каждой реплике и
  усреднённые). Конструкции v2.3 сохраняются только для этого описания и больше не являются
  **[пилот]**: L — уровни, достигнутые хотя бы на 80 % фолдов пилотного периода;
  `L_a = {g ∈ L : g ≤ g*}`; `F_a` и `F_b` — фолды, где достигнуты все уровни `L_a` и L.

**(а) Возмущение весов на оптимальном носителе — описательно.**
- `w(t) = (1 − t)·w* + t·v`, `v ~ Dirichlet(1)` на `supp(w*)` с отбором по `v ≤ u`.
- t подбирается бисекцией. Проекция не нужна: выпуклая комбинация допустимых точек допустима.
- Оговорка: в среднем v — равные веса, поэтому (а) работает как сжатие к 1/K. Это регуляризация,
  которая может улучшать результат вне выборки.

**(в) Инкумбенты реальных решателей — для H3c.** SCIP с лимитом 10 с; tabu, SA и LS с бюджетом
1 с end-to-end.

**Набор фолдов `F_k`.**
- `F_k` — фолды подтверждающего периода, где сертифицированы оптимум и все ранги, нужные анализу:
  для FF49 — ранги 2–33 в каждом плече, для US — ранг 2. Для FF49 набор общий для плеч MV и GMV:
  фолд остаётся, только если условия выполнены в обоих плечах. Так контраст плеч (§10) считается
  на одних фолдах.
- Иначе фолд исключается **из всех путей** (оптимум и ранги), и панель сбалансирована. Фолд, где
  различных доведённых портфелей меньше R + 1 (вырожденный, `N_f ≤ K + 1`), тоже исключается.
- Отбора по структуре зазоров нет. На исключённых фолдах из сравнения выпадают дни тестового окна
  у всех путей.
- Отчитываются доля исключённых фолдов, распределение `ĝ_{f,2}` (медиана, квартили, доля
  `≤ g* = 10` б.п.) с разбивкой по связывающим и несвязывающим фолдам и распределения `ĝ_{f,r}` по
  рангам.

**Метрики RQ3 (N1, N3).**
- **Путь ранга r** — walk-forward, в котором на каждом фолде `F_k` держится портфель ранга r.
- **MV, первичная:** разность годового Sharpe избыточной доходности **до издержек** (путь ранга r
  минус оптимум).
- **MV, вторичные:** чистый Sharpe, разность CE (γ = λ_f), оборот, издержки.
- **GMV, первичная:** отношение дисперсий вне выборки; эквивалентность —
  `log(1 − δ) ≤ log(σ²_r/σ²_*) ≤ log(1 + δ)`. Вторичная — Sharpe до издержек.
- **«До издержек»** — проход движка с `tc = 0`: решения MV и GMV от издержек не зависят (оборота в
  цели нет). RF, исполнение, дрейф и вселенная — как у основного прохода.

**Гипотезы.**

**H3a (эквивалентность, ранг 2).** Путь ранга 2 против оптимума. Первичный тест — **FF49-MV**.
Вторичные подтверждающие — FF49-GMV и US-MV, Holm по двум (N3): отдельно для p-значений TOST и
для двусторонних p-значений. p-значение TOST — наименьшее α, при котором `1 − 2α`-интервал лежит
внутри маржи.
- **Маржа MV:** SESOI 25 б.п. CE в год. `Δ_SR = 0.0025/σ*`, где σ* — годовая волатильность
  избыточной доходности оптимума MV до издержек на пилотном периоде FF49 **[пилот]**. US использует
  ту же `Δ_SR`. Чувствительность: `Δ_SR ∈ {0.02, 0.05}`.
- **Маржа GMV:** `|σ²_r/σ²_* − 1| ≤ δ`, где `δ = (0.005/λ_f)/σ²_*`, а `σ²_*` — дисперсия
  оптимума GMV на пилоте **[пилот]**. Числитель — приращение дисперсии, равное тем же 25 б.п. CE:
  `(λ_f/2)·Δσ² = 0.0025`.
- **Процедура:** TOST по 90 % ДИ разности (ранг 2 минус оптимум) и двусторонний тест на
  α = 0.05, по одному тесту каждого вида на плечо.
- **Исходы:**

  | TOST | Двусторонний | Исход |
  |---|---|---|
  | проходит | не значим | «эквивалентны» |
  | проходит | значим | «различимы, но в пределах SESOI» |
  | не проходит | значим | «различаются» (знак — из оценки, величина — из H3b) |
  | не проходит | не значим | «неопределённо» |

**H3b (доза–ответ по рангам, двусторонний).**
- Оцениваемая величина — наклон МНК b регрессии `ΔSR(r)` на `log ḡ_r` по рангам
  `r ∈ {2, 3, 5, 9, 17, 33}` на `F_k`. Здесь `ḡ_r = mean_{f∈F_k} ĝ_{f,r}`, а `ΔSR(r)` — разность
  Sharpe до издержек пути ранга r и оптимума.
- `ḡ_r` не убывает по r по построению, поэтому разброс по оси x есть. Значения x детерминированы в
  выборке и общие для всех бутстрап-выборок: неопределённость наклона — только по времени.
- ДИ — процентильный 95 %, совместный круговой блочный бутстрап семи путей (оптимум и шесть рангов),
  B = 4999, длина блока — §7.4. Тест двусторонний: значим, если ДИ не накрывает 0.
- Первичный тест — FF49-MV, отдельно (как у H3a). FF49-GMV — вторичный (наклон логарифма отношения
  дисперсий), один тест на α.
- Чувствительность: регрессор `log r`; все ранги 2–33.
- Если какой-то `ḡ_r ≤ 0` (ничьи с оптимумом на всех фолдах), логарифм не определён и H3b
  описательная. Рычаг точки ранга 2 в регрессии отчитывается.
- Интерпретация — «вдоль ряда лучших альтернатив», а не эффект постоянной дозы. Вывод «каждые x б.п.
  зазора стоят y б.п. вне выборки» допустим только при значимом b, а не из неудачи TOST.

**H3c (калибровка реальных решателей, FF49-MV).**
- Для tabu, SA и LS (оператор (в); конфигурации, настроенные для N = 100) остаток — наблюдаемая
  разность Sharpe до издержек (путь решателя минус оптимум, на `F_k`) минус предсказание кривой H3b
  `a + b·log(доза)`.
- Доза — средний по `F_k` фактический `ĝ_CE` решателя (ноль, где он нашёл оптимум). Предсказание
  делается, только если доза лежит в `[ḡ_2, ḡ_33]`; иначе H3c для этого решателя описательная. Это
  приближение: решатель смешивает ранг 1 на большинстве фолдов и ранги r на некоторых, а кривая
  построена по путям «всегда ранг r».
- Описательно: распределение рангов решателя по фолдам (1; 2–5; 6–33; > 33).
- Каждый остаток проверяется TOST с маржой `Δ_SR`; IUT — конъюнкция по решателям с
  предсказанием. SCIP исключён: его зазор нулевой по построению.
- Чистая разность Sharpe фактических путей и их оборот отчитываются отдельными оценками с ДИ
  (stationary bootstrap, §7.4): у реальных решателей лишний оборот — часть поведения.
- H3c описательная, если меньше двух решателей имеют медианный по `F_k` фактический зазор ≥ 1 б.п.
  или если предсказание есть меньше чем у двух решателей. На FF49 при N ≈ 49 это вероятно, и об
  этом сказано заранее (minor 11).

**Позиционирование.** Ядро «после некоторой точности улучшение не окупается» есть у Gilli &
Schumann (J. Heuristics 2011; Ann. Oper. Res. 2012). Наш вклад — формализация:
- сертифицированный оптимум и сертифицированные k лучших альтернатив с фактической дозой;
- цель с μ против GMV;
- эквивалентность;
- данные с контролем выживаемости.

Без формулировки «впервые».

**Мотивация (разведочно, legacy-данные, E0 v5).** При одном правиле решений tabu промахивается
мимо сертифицированного оптимума на части фолдов, а разница вне выборки после Holm незначима
(`runs/20261004-222712-…`, `runs/20261004-224319-…`). В рукописи это мотивация, не результат.

    дивидендов MCFTR − IMOEX.

**Walk-forward (M13, N4).**
- Обучение 756 дней, тест 21 день, шаг 21; μ — выборочное среднее, Σ — Ledoit–Wolf; внутри окна
  покупка и удержание с дрейфом (R1).
- u: FF49 — 0.20, US — 0.10.
- `K_f = max(⌈1/u⌉ + 1, ⌊s_cont,f/2⌋)`, `s_cont,f` — на обучающем окне (без заглядывания вперёд).
  Задача связывает тогда и только тогда, когда `s_cont,f > ⌈1/u⌉ + 1`.
- **Рычаг связывания:** `λ_f` — наименьшее из {5, 10, 20}, при котором на пилотных фолдах FF49
  `s_cont,f > ⌈1/u⌉ + 1` хотя бы на 70 % **[пилот]**. Если такого нет, `λ_f = 20`, доля
  отчитывается, и RQ3 идёт на всех фолдах. US использует то же λ.
- Отчитываются доля связывающих фолдов и доля фолдов, где действует нижняя граница
  `K = ⌈1/u⌉ + 1`: в этом режиме `K·u ≈ 1`, и веса почти фиксированы.
- Издержки: 10 б.п. на торгуемый номинал (основное), чувствительность 0 и 30 б.п.
- Цель — чистая MV или GMV; вариант с оборотом — разведочно.
- Задержка исполнения на 1 день — проверка устойчивости (`execution_lag`, O-9).

## 5. Метрики

**Нормировка зазора (M10).**
- `ĝ(f) = (f − f_ref) / s_ref`, где `s_ref = |μᵀw_ref| + (λ/2)·w_refᵀΣw_ref > 0`. Знаменатель
  положителен и через ноль не проходит.
- Тип опоры `ref_type ∈ {certified, best_known}` (R9). В RQ3 зазор — в б.п. годового CE.
- Primal gap Бертольда — вторично, для сравнимости с литературой MIP.
- Код `cif.metrics.gap` дополняется аргументом масштаба до пилота.

**Сертификат.** Абсолютный зазор SCIP `limits/absgap = 10⁻⁶·s_ref`, считать до закрытия (предел
2 ч). Нужен там, где нужен оптимум: `f*` в RQ1, `w*_f` и ранги (г) в RQ3.

**Primal integral (M8, N5).**
- `PI(T) = (1/T)·∫₀ᵀ γ(t) dt`, где `γ(t) = min(1, ĝ(f_inc(t)))`, опора — лучшее известное значение
  по всем методам.
- Несертифицированные инстансы в RQ2 не исключаются.
- **Общий старт:** top-K rounding непрерывной релаксации с доводкой передаётся **всем методам**
  как тёплый старт: SCIP — через `addSol`, OA — как начальный инкумбент, LS — как стартовая точка,
  конвейер — в пул. Время его построения засчитывается всем, и с этого момента γ у всех методов
  не выше его зазора.
- Задержка до первого *собственного* решения отчитывается отдельно. Варианты для
  чувствительности: `γ = 1` до собственного первого решения и confined primal integral (Berthold &
  Csizmadia 2021).
- Время end-to-end: построение модели или QUBO, решение, доводка.

**Траектории anytime (N5).**
- SCIP — обработчик событий новых решений.
- OA — инкумбент после каждой итерации мастер-задачи.
- Эвристики — после каждого пакета внешнего цикла (§6).
- LS — после каждого улучшающего обмена.

**Time-to-target (вторично).**
- Время end-to-end до `ĝ ≤ τ`, `τ = 10⁻³` (основное) и `10⁻⁴` (чувствительность).
- Прогон, не достигший цели, цензурируется на бюджете; медиана по сидам — Каплан–Мейер.
- Чувствительность — к бюджету цензурирования, а не исключение цензурированных (minor 9).

| RQ | Первичная | Вторичные |
|---|---|---|
| RQ1 | `E_form(m)`, `E_samp(m)` в нормированных абсолютных единицах с ДИ | доля допустимых сэмплов; τ Кендалла между энергией суррогата и `F(S)` |
| RQ2 | отношение PI за 60 с (общий старт) | TTT; `t_primal`, `t_cert`; задержка первого решения; performance profiles |
| RQ3, MV | разность Sharpe избыточной доходности до издержек | чистый Sharpe; разность CE; оборот; издержки |
| RQ3, GMV | отношение дисперсий вне выборки | Sharpe до издержек |

## 6. Протокол вычислений

- **Машина для таймингов:** выделенный CPU-сервер в монопольном режиме (решение пользователя
  2026-10-08: вместо кластера cHARISMa). Модель сервера фиксируется до пилота и пишется в §12.
  - Одновременно — не больше однопоточных задач, чем половина физических ядер.
  - В манифест пишутся модель CPU, регулятор частоты и настройки потоков (R10).
  - Ноутбук — только smoke-прогоны.
- **Один поток** для всех решателей (`single_thread_env`, `threads = 1` у SCIP и HiGHS).
- **Внешний цикл эвристик (N6).** Эвристика повторяет пакеты до исчерпания бюджета wall-clock.
  - Пакет: вызов сэмплера (SA — `num_reads_b` чтений; tabu — `num_restarts_b` рестартов; swap-SA —
    `num_reads_b`), затем доводка новых уникальных подмножеств пакета, по энергии, не больше `m_b`.
  - Пул накопительный, без повторной доводки.
  - Пакет, который не уложится в остаток бюджета, прерывается: у SA и swap-SA — через
    `interrupt_function`, у tabu — уменьшением числа рестартов.
- **Бюджеты.**
  - RQ2: 60 с end-to-end (N ≤ 400).
  - H1c: 10 с end-to-end.
  - RQ1 (атрибуция): один вызов сэмплера без внешнего цикла. Работа вызова фиксирована (чтения ×
    развёртки у SA и swap-SA, рестарты у tabu). Она подбирается на пилоте так, чтобы медианное
    время вызова настроенной конфигурации на калибровочных парах данного N было ≈ 1 с **[пилот]**.
    Уровни вложенных факторов §7.3 используют ту же работу; время вызова отчитывается (v2.4).
  - E3 (в): 1 с.
- **Сиды.** Эвристики — 10 на инстанс. SCIP — ≥ 3 сида перестановок (`randomization/permutationseed`,
  `permutevars`, `randomseedshift`; реализуется до пилота).
- **Настройка (N6).**
  - Каждая эвристика и выбор варианта точного метода: до 30 конфигураций, случайный поиск в
    пространстве приложения Б.
  - Калибровочный набор того же N (§3), по 3 сида.
  - Критерий — медианный по инстансам PI за 10 с (для H1c — медианный итоговый зазор за 10 с).
  - Победитель перепроверяется на 60 с на калибровке. Если на 60 с он хуже второго места больше
    чем на 5 %, выбирается второе место.
  - Ничья в пределах 5 % решается по меньшей медиане TTT.
- **Представители классов** — по тому же критерию, после настройки (§2 RQ2).
- **Масштаб штрафа:** `selection_penalty_scale` (`cif.qubo.builder`), множители {1, 3, 10, 30, 100}
  (minor 4).
- **TTT-кривые** (Aiex, Resende & Ribeiro 2007): 100 прогонов на 3 инстансах. Инстансы — с
  медианной трудностью (медианный PI точного представителя) среди калибровочных при N = 200
  (minor 10).
- **Регистрация.**
  - Раннер `cif.experiments.run` по YAML-конфигу.
  - Подтверждающие прогоны — только с чистого дерева, после публичной метки.
  - Входные данные хешируются в манифест.
  - Без записи в реестре результат не используется.

### 7.2. RQ1–RQ2 (по инстансам)

- Сводка по инстансу — медиана по сидам; доля успехов — с ДИ Уилсона.
- Средние логарифмов отношений — со стратифицированным бутстрапом: инстансы внутри ячеек, port в
  ORlib.
- Performance profiles (Dolan & Moré 2002) и TTT-кривые — описательно.

### 7.3. Модели атрибуции RQ1 (N10)

- Отклик — `asinh(E_samp(m)/τ)`: знаковое преобразование, определено и при `E_samp < 0`.
- Факторы вложенные, а не скрещённые, поэтому модели отдельные по сэмплерам:
  - SA: множитель штрафа × диапазон β × `log m`;
  - tabu: множитель штрафа × `log m`;
  - swap-SA: `log m`.
- Во всех моделях — фиксированные эффекты N и h и случайный эффект инстанса.
- Контраст между сэмплерами — при настроенных конфигурациях.
- Отчитываются оценки с ДИ; тестов нет (разведочно).

### 7.4. RQ3 (временные ряды)

- **Разность Sharpe:** тест Ledoit & Wolf (2008), studentized circular block bootstrap, доходности
  в процентах. HAC (QS с предотбеливанием) — проверка устойчивости (`cif.stats`). Бутстрап
  совместный по временным блокам для всех путей рынка и плеча; единица вывода — время. Для
  описательного (б) разность считается по каждой реплике и усредняется.
- **Стандартная ошибка контраста** (разности, наклона, остатка) — HAC (QS с предотбеливанием) ряда
  влияния линеаризованного контраста. Это дельта-метод LW2008; от четырёхмоментной HAC LW он
  отличается только выбором полосы.
- **Длина блока** — калибровка LW2008 (алгоритм 3.1) на паре (оптимум, ранг 2) по статистике
  плеча (разность Sharpe у MV, разность логарифмов дисперсий у GMV), отдельно для каждого рынка и
  плеча: сетка дневных блоков {1, 5, 10, 21, 42, 63, 126}, 1000 псевдорядов, 499
  повторов, сид фиксирован. Найденная длина используется для всех рядов совместного бутстрапа этого
  рынка и плеча. Для (б) — пара (оптимум, среднее реплик).
- **Чувствительность к длине блока** (описательно): H3a и H3b обоих плеч с фиксированными блоками
  21 и 63 дня. Псевдоряды VAR(1) алгоритма 3.1 не воспроизводят кластеризацию волатильности, и на
  GARCH-синтетике калибровка чаще выбирает блок 1 с покрытием чуть ниже номинала (разведочно,
  E0).
- **Отношение дисперсий (GMV):** студентизованный круговой блочный бутстрап по схеме LW2008 для
  разности логарифмов дисперсий; стандартная ошибка — HAC с дельта-методом.
- **Нестьюдентизованные статистики** (разность CE, оборот): stationary bootstrap (Politis & Romano
  1994), длина блока по Politis–White с поправкой Patton–Politis–White (2009).
- **Пилот мощности [пилот]** — FF49, пилотный период:
  - корреляция ρ доходностей пути ранга 2 и оптимума;
  - полуширина 90 % ДИ, пересчитанная с длины пилота на длину подтверждения:
    `∝ √(T_пилот / T_подтв)`.
  - Если пересчитанная полуширина больше Δ, исход «неопределённо» ожидаем. Это пишется в §12, но
    дизайн не меняет.
- **RU (разведочно):** первичная метрика — разность CE, безусловно (N3).

## Приложение Б. Пространства настройки (до 30 конфигураций на метод)

- **SA:** чтений в пакете `num_reads_b` ∈ [10, 1000]; развёрток ∈ [100, 10 000]; диапазон β — по
  умолчанию или по масштабу цели; множитель штрафа ∈ {1, 3, 10, 30, 100}; доводка на пакет
  `m_b ∈ {20, 50, 200}`.
- **Tabu:** рестартов в пакете `num_restarts_b` ∈ [1, 100] (детерминированный режим, R12); tenure ∈
  [5, N/2]; множитель штрафа и `m_b` — как у SA.
- **Swap-SA:** `num_reads_b` ∈ [10, 500]; длина цепи ∈ [10·N, 1000·N]; температура — по калибровке
  горячей температуры; `m_b` — как у SA.
- **LS:** число рестартов ∈ [1, 200]; первое или лучшее улучшение; окрестность — обмен одной бумаги.
- **Точные:** вариант из {SCIP big-M, SCIP perspective-λ_min, SCIP perspective-SDP (N ≤ 150), OA
  HiGHS multi-tree}; у SCIP — `misc/usesymmetry` ∈ {по умолчанию, 0}; остальные параметры — по
  умолчанию. Обнаружение симметрии в предобработке SCIP не смотрит на часы: разведочно при
  N = 400 оно заняло 5.7–23 с бюджета в 10 с, не найдя симметрии.
