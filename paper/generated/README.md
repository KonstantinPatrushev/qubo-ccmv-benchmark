# paper/generated/ — только генерируется кодом

Не редактировать вручную. Содержимое создают аналитические скрипты (`stats-analyst`) из
зарегистрированных прогонов `runs/`:

- `numbers.tex` — `\expandafter\def\csname res@<ключ>\endcsname{<значение>}`; над каждым ключом
  — комментарий с `run_id` источника;
- `tables/*.tex` — таблицы для `\input{}`;
- `figures/*.pdf` — рисунки.

Перегенерация — одной командой (появится в E0), её выполняет `replicator` на G4.
